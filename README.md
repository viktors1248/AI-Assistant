# 🤖 AI Assistant for Blinds Installation Company

## 📋 Project Overview

An intelligent conversational AI assistant designed for **zaluzi.lv** (SIA "WWW.ŽALUZI.EU"), a leading manufacturer of blinds and sun protection systems in Latvia, the Baltic States, and the EU. The assistant automates customer communication, provides instant support, and streamlines the appointment booking process.

## ✨ Key Features

*   **🗣️ Intelligent Dialogue:** Conducts meaningful, context-aware conversations using advanced neural networks to understand user intent and guide them through the selection process.
*   **📚 Knowledge Base Q&A:** Provides accurate, instant answers to customer questions based on a comprehensive database of products, services, and company policies.
*   **📅 Automated Scheduling:** Handles client meeting bookings seamlessly by integrating with **Google Calendar** to schedule free on-site measurements and installations.

## 🛠️ Tech Stack & Services

*   **Qwen:** Utilized for creating the systematic prompt and structuring the knowledge base, ensuring high-quality, relevant responses.
*   **Suvvy.ai:** The core platform used for building and deploying the AI assistant, managing dialogue flows, and handling integrations. [Visit Suvvy.ai](https://suvvy.ai/)
